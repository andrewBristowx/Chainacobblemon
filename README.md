# Chainacobblemon

Base independiente para el servidor Cobblemon de Chaina.

## 0.1.0-alpha.1

Primera alpha tecnica, derivada exclusivamente del subsistema generico y ya validado de emotes/chat de el proyecto tecnico anterior. No incluye contenido tematico anterior.

Incluye:
- selector de emotes dentro del chat;
- Twitch / 7TV / BTTV / FFZ mediante Streamotes 1.2.12+1.21;
- canal oficial `chainavt`;
- favoritos y recientes;
- buscador;
- cache local persistente;
- precarga escalonada de previews para evitar picos de lag;
- insercion `:emote:` manteniendo el foco del chat;
- proteccion contra sustitucion accidental al exigir codigos explicitos;
- colores originales de los emotes;
- interfaz temporal neutra a la espera de la fase visual de Chaina.

No incluye aun gacha, economia, Pokemon personalizados, armas/armadura, NPCs, pase, login diario, dungeons ni assets visuales de Chaina; se incorporaran por versiones sin arrastrar contenido tematico anterior.
